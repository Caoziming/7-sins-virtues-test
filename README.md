# 七宗罪 × 七美德 测试

一个纯前端的性格小测试:28 道题,测测你的灵魂天平偏向「七宗罪」还是「七美德」。

## 特性

- 单文件、零依赖:`index.html` 双击即用,离线可跑
- 28 道题(7 个「罪↔德」维度 × 4 题),每次作答顺序随机
- 结果页:总评称号、主罪/主德卡片(黑夜/白昼主题)、七维倾向条、可展开的逐题解析
- 分享链接:作答编码进 URL(`#r=...`),朋友打开链接直接看到你的结果,无需服务器

## 使用

直接双击 `index.html`,或部署到任意静态托管(GitHub Pages / Netlify / OSS 等)。
